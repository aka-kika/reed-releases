# Reed releases

Download and update feed for **Reed**, a Markdown workspace for macOS by [aka-kika](https://github.com/aka-kika).
The source lives in a private repository; this public one only carries the signed,
notarized builds and the Sparkle appcast so the app can update itself.

- Latest release: https://github.com/aka-kika/reed-releases/releases/latest
- Update feed (Sparkle): `appcast.xml` on `main`
- Website: https://thereed.dev

Install: open the DMG, drag Reed into Applications. Releases are Developer ID signed and notarized.
